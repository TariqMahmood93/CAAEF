CAAEF experiment folder
1. Open the file named .env (hidden by default: Mac Cmd+Shift+. ; Windows View > Hidden items)
   and paste your OpenAI key and your Anthropic key in place of the two placeholders.
2. Open experiment_prompt.md and fill in the spending limit.
3. Start Claude Code in this folder and paste everything below the line in experiment_prompt.md.
   Claude Code will propose the models and ask you to approve them.
